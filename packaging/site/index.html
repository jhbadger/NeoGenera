NeoGenera

A Lisp environment evoking the Symbolics Genera workstations: one live, introspectable system.

ManualsAPI referenceExamplesTour (asciicast)MIT license

NeoGenera is a Common Lisp subset with a bytecode compiler that compiles itself, a text-mode window system with mouse-sensitive output, an Emacs-style editor, an Inspector, cross-reference, trace, stepper and profiler, integrated hypertext documentation, and libraries for mathematics, statistics and bioinformatics. It is implemented in C and in itself.

$ make world            # build the kernel and the self-hosted system image
$ bin/neogenera --ui    # the window system: Listener, editor, Inspector, documentation viewer
CL-USER> (translate "ATGGCCATTGTAATGGGCCGCTGAAAGGGTGCCCGATAG")
#<PROTEIN 13aa MAIVMGR*KGAR*>
CL-USER> (t-test control :y treated)
Welch Two Sample t-test ... p-value = 0.00178
CL-USER> :doc user-guide

What is in it

  • A Lisp you can read. A small C kernel (about 8,000 lines) and a system written in Lisp; the compiler reaches a byte-identical fixed point.
  • Click on results. Every printed object is a presentation: click a sequence, an alignment or a tree for commands that apply to it.
  • Documentation inside the system. Manuals, docstrings and cross-references in one viewer, exported to HTML and PDF.
  • Quantitative work. Linear algebra, distributions, tests and models validated against R and NIST reference values.
  • Bioinformatics. FASTA, FASTQ, GenBank, GFF, VCF, SAM and BAM; alignment, search, motifs and trees.
  • Hardened. Fuzzed parsers, recoverable memory and stack exhaustion, checksummed crash-safe images, reproducible builds.

Get it

Build from source (a C compiler and make are enough), or use the Debian package, Homebrew formula or Docker image described in the README. See docs/COMPATIBILITY.md for how NeoGenera differs from ANSI Common Lisp.
