# Code of conduct

We want NeoGenera to be a place where people can learn and build without being treated badly. Be kind, assume good faith, and
keep criticism about the work. Harassment, personal attacks and discrimination are not welcome in issues, pull requests, discussions
or any project space. Maintainers may edit or remove contributions that break these rules and may ban repeat offenders.
Report problems to the maintainers privately. This text is adapted from the spirit of the Contributor Covenant.
